# Axiom Forge Systems — visual system and asset plan

This is a fictional portfolio concept. Generated equipment and site images are illustrative, not proof of completed work or verified specifications.

`design-concept-preview-v2.webp` is the polished AI-generated art-direction preview, not a screenshot of the implemented website; use the running site as the source of truth for layout and copy. The earlier `design-concept-preview.webp` is retained as an iteration.

## Direction

Quiet industrial precision: premium architectural editorial photography meets a serious engineering catalogue. The hero stays grounded in a believable test bay; an early compact four-card product rail follows it. Alternate cinematic graphite with warm-light reading surfaces. Avoid neon, sparks, decorative blueprint grids, fictional badges, and baked-in image text.

- Palette: graphite `#0a0c0f`, surface `#12161b`, warm off-white `#eef1f3`, signal orange `#ff5a1f`. Orange marks decisions and actions, not broad backgrounds.
- Type: Manrope Variable for tight display headlines, Inter Variable for body and specifications. Headlines break intentionally; technical labels remain compact but readable.
- Composition: generous outer margins, fine rules, asymmetrical case-story layouts, useful technical plates. The supplied card reference guides the four-up rhythm, isolated equipment, restrained orange arrows, and fine borders; narrow screens become a swipeable rail.
- Imagery: physically plausible machinery with consistent steel/graphite grading. Product cutouts use transparent optimized WebP; projects use distinct environmental photographs. No operational proof should be inferred from generated imagery.
